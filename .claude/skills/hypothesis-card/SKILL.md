# hypothesis-card — 반증 가능한 가설 카드

`research/ideas/idea-NNN.md`를 만든다. 틀은 `research/ideas/TEMPLATE.md`.

## 이 카드가 강제하는 것

```
id / 주장(한 문장) / 근거 / 반증 조건 / 필요한 실험 / 상태
```

**반증 조건이 비면 카드를 완성하지 않는다.** 이건 서식 규칙이 아니라 이 프로젝트가
지키기로 한 것이다 — 반증 조건 없는 가설은 어떤 결과가 나와도 사후에 성공으로 읽을 수
있어서, 검증 단계를 통째로 무력화한다.

## 주장 쓰기

한 문장, 수치 포함, 틀릴 수 있는 형태.

| ❌ | ✅ |
|---|---|
| PASN이 MBE보다 좋다 | `T=8`에서 ΔPPL이 `+0.1%` 이내다 |
| 메모리 효율이 개선된다 | 중립 규약에서 파라미터가 MBE의 `1.2×` 이하다 |
| 라우터가 도움이 된다 | `e_min=-6`이 `-3`보다 스파이크를 `1.3×` 이상 줄인다 |

## 반증 조건 쓰기

**사전에, 숫자로.** 그리고 **사후에 넓히지 않는다.**

이 프로젝트는 사전등록 게이트를 한 번 놓쳤다(0.187% > 0.14%). 그때 밴드를 넓히지
않기로 결정했고, 결론은 안 흔들렸다(놓친 폭이 마진의 2.7%). 그 결정을 되돌리지 않는다.

조건은 실험을 돌리기 **전에** 확정한다. 결과를 보고 정하면 그건 조건이 아니라 해설이다.

## 설계 점검 — GPU를 쓰기 전에

카드를 닫기 전에 확인한다. 이 목록은 실제로 시간을 날린 것들이다.

- [ ] **프리즈 빌드로 돌리는가?** 아니면 왜 아닌지 적었는가
- [ ] **운영점을 정했는가?** T, arm, stride — 없으면 결과를 나중에 인용 못 한다
- [ ] **seed 스윕이 아닌가?** 빌드가 결정론적이다. 이미 1시간 45분 날렸다
- [ ] **1-D 적합을 균일 그리드에서 채점하지 않는가?** 큰 값이 지배해서 0 근처가
      망가진 적합도 좋아 보인다. 네트워크가 먹이는 분포에서 원소별 상대오차로 잰다
- [ ] **내부 MBE 베이스라인을 스윕해서 최선을 취하는가?** 적합이 `N`에 비단조라
      단일 설정은 임의의 점을 찍는다
- [ ] **등정확도 비교인가?** 단일 운영점 비교는 정확도를 스파이크로 살 수 있다
- [ ] **`PAPER_PLAN.md` §6이 "채울 수 없다"고 결정한 칸이 아닌가?**
- [ ] **`PAPER_PLAN.md` §5 "하지 말 것"과 충돌하지 않는가?**

## 승격

카드는 **스테이징이다.** `PAPER_PLAN.md` §2가 실험 우선순위의 단일 출처이고,
승격은 **사람이** 한다. 카드를 직접 §2에 쓰지 마라 — 두 번째 진실원이 생기면
어느 쪽이 최신인지 아무도 모르게 된다.

흐름: 카드 작성 → 사람이 반증 조건 승인 → 사람이 §2로 승격 → runner가 실행.
